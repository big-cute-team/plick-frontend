### 거짓 양성으로 배제한 것

- **`rounded-hero`·`pb-section`(mobile)**: 서브에이전트가 "데스크톱 전용 토큰"으로 의심했으나, `--radius-hero`·`--spacing-section`은 `theme.css`의 일반 `@theme` 블록 소속이고 `screen-publishing` 스킬이 모바일 유효 토큰으로 명시 → 위반 아님.
- **미디어 스크림 3형제(HotCard·SuggestedArticleCard·ReelCard)**: 같은 스크림 패턴이나 비율·제목 스케일이 달라 JSDoc이 의도적 분리를 명시 → 통과. 모든 스크림이 `var(--plk-scrim)`+color-mix 규칙 준수(raw rgba 아님).
- **TopBar 변형군(EditTopBar·OnboardingTopBar·ArticleTopBar·TopBar)**: 공용 `TopBarShell`을 이미 재사용하고 내부 콘텐츠만 달라 통합 불필요.
- **team picker UI(pill 칩 vs 그리드 카드)**: `useTeamSelection`+`TEAMS`는 이미 공유, UI 요구가 실제로 달라 통과(단, 크레스트 카드 마크업 자체는 🔴 #4로 별도 지적).
- **패키지 파일명 PascalCase**: `@plick/ui/<Name>` 서브패스와 1:1 매칭되는 패키지 관례 → 위반 아님.
- **아이콘 유사명(Bell/BellLine, User/UserRound, Search/SearchLine)**: path 데이터가 실제로 다른 별개 벡터 → 의도된 별개.

**죽은 코드**: `RailTone` export 1건(🔵 #1) 외 없음. 아이콘 28종 전부 사용, `@plick/ui` 컴포넌트 12종 전부 사용.
