## 소유 지표 — 초기 JS 전송량 (reels-run3)

| 항목                        | before        | after                    |
| --------------------------- | ------------- | ------------------------ |
| 초기 버스트 JS (~85ms 출발) | 14건 226.6 KB | 15건 218.7 KB (−7.9 KB)  |
| idle 프리페치 청크          | -             | 2건 10.2 KB (768ms 출발) |

시트·다이얼로그 몫 중 약 18 KB가 초기 버스트에서 빠졌고, 그중 시트 청크
10.2 KB는 idle 프리페치로 뒤늦게 내려온다(첫 탭 대비). 나머지 다이얼로그
(공유·로그인·신고·삭제 확인)는 첫 탭 때 받는다. 기사 상세·토론 라우트도 같은
컴포넌트를 쓰므로 초기 그래프가 같이 얇아진다.

계획(ADR 0113)에서 이 레버의 지표로 적었던 TBT는 before가 이미 3.5ms라 측정
대상에서 뺐다. CLS 0.052는 KAN-422 시점부터 있던 기존값으로 이 PR과 무관하다.
