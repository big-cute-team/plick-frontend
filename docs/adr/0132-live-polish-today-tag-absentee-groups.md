# 0132. 라이브 스코어 다듬기 — 오늘 태그, 결장자 팀별 묶기, 국대 대회 숨김, 날짜 스트립 센터링 완화 (KAN-459)

2026-09-08. 브랜치 `feature/KAN-459-live-polish`.

## 뭘 받았나

KAN-458 채팅까지 붙이고 나니 라이브 지면을 실제로 써 본 피드백이 티켓으로 왔다. 네 줄짜리 짧은
티켓인데 손대는 곳은 도메인·경계 변환·모바일·웹 네 층에 걸쳐 있었다.

1. 날짜 스트립에서 오늘 칸에 "오늘" 태그를 붙일 것
2. 선수 시즌 스탯에서 월드컵과 친선경기(friendlies) 줄을 없앨 것
3. 결장자를 팀별로 나눠 보여줄 것
4. 날짜를 고를 때마다 스트립이 자동으로 가운데로 스크롤되는 걸 없앨 것. 처음 들어왔을 때만
   오늘이 가운데 오면 되고, 그 뒤 선택은 그 자리에 두라는 것

## 1. 오늘 태그

스트립 칸은 요일(위)과 날짜(아래) 두 줄이다. "날짜 위에 태그"라고 했으니 위 줄이 자리인데,
칸 하나만 세 줄이 되면 옆 칸과 높이가 어긋나 스트립 전체가 들쭉날쭉해진다. 모든 칸에 태그 자리를
비워 두는 방법도 생각했는데 그러면 빈 줄 하나만큼 스트립이 키만 커진다.

그래서 오늘 칸은 요일 대신 "오늘" 필을 그리기로 했다. 같은 `text-micro` 줄이라 높이가 그대로고,
오늘이 무슨 요일인지는 사용자가 안다. 색은 선택 상태에 따라 갈라진다. 오늘이면서 선택된 칸은
바탕이 이미 `bg-accent-tint`라 필을 `bg-accent text-on-accent`로 진하게, 오늘이지만 다른 날을
보고 있을 땐 `bg-accent-tint text-accent`로 연하게 둔다. 두 상태가 한 화면에 같이 나오는 일은
없지만(오늘은 하나니까) 다른 날을 골랐을 때 오늘 칸이 어디 있는지 눈에 띄는 게 목적이라
연한 쪽도 필 모양은 유지했다.

`today`는 페이지가 KST로 계산해 props로 내려주는 값이라(하이드레이션 어긋남 방지, ADR 0129)
스트립 안에서 다시 계산할 필요는 없었다. `dateKey === today` 한 줄이다.

## 2. 국가대표 대회 숨기기

BE는 대회명을 `league-names.csv` 사전(프리미어리그·FA컵·리그컵·커뮤니티 실드·챔스·유로파·
컨퍼런스·클럽 친선경기 여덟 개)으로 한글 치환하고, 사전에 없는 대회는 API-Football 영문명을 그대로
내린다. 월드컵(`World Cup`, `World Cup - Qualification Europe`)과 A매치 친선(`Friendlies`)이 그
영문 폴백으로 시즌 스탯 표에 섞여 들어온 거다. 응답에 리그 id는 없고 이름뿐이라 이름 패턴으로
거를 수밖에 없었다.

패턴은 `@plick/domain/live`의 `HIDDEN_SEASON_COMPETITION = /world cup|friendlies/i`로 뒀고, 거르는
자리는 `packages/core/src/live.ts`의 `getPlayerSeasonStats` 경계 변환 한 곳이다. 시트(모바일)와
모달(웹)이 같은 훅으로 같은 함수를 부르니 화면 쪽은 손대지 않았다.

사전에 있는 "클럽 친선경기"(id 667)는 한글이라 패턴에 안 걸리고 남는다. 티켓이 영어로
"friendlies"라고 쓴 건 화면에 영문 그대로 뜬 A매치 친선을 가리킨 거라고 읽었고, BE가 일부러 사전에
올린 클럽 친선까지 지우는 건 과하다고 봤다. 반대로 "Friendlies Clubs"처럼 영문 폴백으로 오는 변형은
걸린다. 걸린 대회가 전부라 목록이 비면 기존 "이번 시즌 출전 기록이 없어요" 빈 상태가 그대로 뜬다.

## 3. 결장자 팀별로

원래는 결장자 한 줄에 크레스트·사진·이름·사유 배지를 나란히 두고 홈·원정이 섞여 내려온 순서대로
그렸다. 이걸 팀 줄 하나 아래 선수 줄이 들여쓰기로 붙는 2단으로 바꿨다. 팀 줄은 직전 경기 선발
블록과 같은 모양(크레스트 16 + 팀명 볼드)에 인원수를 덧붙였고, 선수 줄에선 크레스트를 뺐다.

묶는 함수는 `groupAbsenteesByTeam`으로 `@plick/domain/live`에 뒀다. 순수 함수라 web·mobile이
같이 쓰고, 그룹 순서는 배열에 처음 등장한 팀 순이다. 홈이 먼저 오게 하려면 누군가 정렬을 해야 하는데
`PreviewBlocks`는 `preview`만 받고 홈·원정 정보가 없다. 컴포넌트에 header를 더 넘기는 대신 경계
변환에서 `absences`를 side 기준(HOME→AWAY)으로 안정 정렬해 두는 쪽을 골랐다. BE 응답 순서에 기대지
않고 FE가 한 번 정렬하니 그룹 함수는 순서 걱정 없이 단순해진다. 빅6 밖 팀은 `id`가 null이라 팀
식별은 `shortName`으로 한다.

## 4. 센터링은 처음과 달 바꿀 때만

원래 센터링 effect는 `[selected]`에 걸려 있어 날짜를 누를 때마다 그 칸을 가운데로 끌어왔다.
티켓은 "처음 들어갔을 때만"이라고 했지만 그대로 마운트 한 번으로 끝내면 드롭다운으로 달을 바꿨을 때
문제가 생긴다. 스트립 내용이 통째로 다음 달 1일~말일로 갈리는데 scrollLeft는 지난 달 보던 위치에
남아, 선택된 1일이 화면 밖에 있는 채로 뜬다. 그래서 의존성을 `[year, month]`로 잡았다. 마운트에
한 번, 달이 바뀔 때 한 번 돌고, 같은 달 안에서 날짜를 고르면 스트립은 그 자리다.

이게 되려면 `?date=` 내비게이션 사이에 `DateStrip` 인스턴스와 스트립 DOM이 살아 있어야 한다.
`Link`로 `/live?date=…`에 가면 같은 라우트 안의 소프트 내비게이션이라 서버 컴포넌트 페이지가
새 RSC 페이로드로 다시 그려지지만, 트리 같은 자리의 클라 컴포넌트는 React가 인스턴스를 유지한다.
스트립 div도 그대로라 scrollLeft가 보존된다. 검증에서 내비게이션 전후 `strip === window.__s`가
true로 나와 확인했다.

## 검증에서 헤맨 것

로컬 BE(8080)는 여전히 `FOOTBALL_API_KEY`가 없어 라이브 API가 전부 502라(ADR 0129) BE mock
프로필(8081)로 갔다. 사용자가 띄워 둔 3001 dev 서버는 하루 넘게 떠 있던 고아 프로세스인데 청크를
500으로 내고 있어 쓸 수 없었고, `API_BASE_URL=http://localhost:8081 pnpm build` 뒤
`.claude/launch.json`의 `mobile-mock`(3011)·`web-mock`(3010)으로 붙였다.

4번 검증에서 한 번 속았다. 오늘(8일)을 센터링한 뒤 10일을 누르니 scrollLeft가 204.5에서 304.5로
바뀌어 10일이 정확히 가운데 왔다. 다시 센터링된 것처럼 보였는데 그다음 5일을 누르면 안 움직였다.
원인은 브라우저 패널이 hidden이면 `requestAnimationFrame`이 멈춘다는 것이었다(메모에도 있던 함정).
마운트 때 걸어 둔 rAF 콜백이 패널이 잠깐 보이는 순간(스크린샷)까지 밀려 있다가, 그때 이미
aria-current가 10일로 바뀐 DOM을 보고 그 칸을 센터링한 거다. 앱 동작이 아니라 측정 잔상이었다.

확실히 하려고 `requestAnimationFrame`을 `setTimeout` 0으로 갈아 끼우고 호출 횟수를 셌다. effect가
돌면 rAF를 최소 한 번 부르니 횟수가 곧 effect 실행 횟수다. 10일·12일을 눌러도 0회, 웹에서 11일도
0회였다. 그 뒤 인스턴스 유지 확인과 함께 4번은 닫았다.

결장자 그룹은 mock 900003에 Arsenal 한 명뿐이라 그룹 하나만 보였다. 여러 팀 묶임과 국대 대회
패턴은 `node --experimental-strip-types`로 도메인 함수를 직접 불러 확인했다(홈 2명·원정 1명 →
그룹 두 개, `World Cup`·`Friendlies`·`Friendlies Clubs` 숨김, `클럽 친선경기`·`UEFA Nations League`
표시). 시즌 스탯 시트는 mock에 국대 대회가 없어 필터 자체는 화면으로 못 봤고 빈 상태 경로만 확인했다.
실데이터 대조는 키가 들어온 뒤로 미룬다.
